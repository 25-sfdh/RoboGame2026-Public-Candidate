# CAD 文件状态

本目录目前**只有说明，没有 CAD 文件**。原归档中的 SolidWorks/STEP/DWG 文件没有复制到本仓库。

## 1. 为什么没有直接上传

1. **公开权限未确认**：本轮没有拿到 CAD/工程图可公开的明确授权；不能因为代码采用 MIT 就推定 CAD 也按 MIT 公开。
2. **第三方模型/标准件**：CAD 中包含 ST3215 舵机、MD36LP27 电机、MGN12C 导轨、05B 链轮/链条、HA8/HP8/HX8 附件、迷你电动推杆等外购件模型；其再分发条款需要逐项确认。
3. **体积与格式**：原归档机械目录约 342 个文件、190.6 MB；GitHub 不适合直接提交大量原生 SolidWorks 文件和重复副本。
4. **版本未清理**：存在完整重复目录、渲染中间文件、AutoCAD/SolidWorks 锁文件和多个升降版本。
5. **未验证**：没有 SolidWorks/STEP 装配查看器，未检查装配配合、干涉、质量和可制造性；不能把未经打开的模型当作已验证发布物。

## 4. 文件验证限制

- **未打开 SolidWorks 装配体**，不能确认配合、干涉、质量属性、BOM 或最终版本。
- `.SLDASM/.SLDPRT` 只核对了文件存在/大小/扩展名，没有验证内部几何。
- 抽样的 `.stp` 文件头以 `ISO-10303-21;` 开头，属于 STEP 文本格式；这不等于几何/装配已验证。
- 抽样的 `.DWG` 文件头为 `AC1021`（AutoCAD 2007 格式），未打开图纸。
- `6-5工程.STEP`（约 147 MB，原归档 `RG/三审前`）是全装配导出候选，未纳入；体积过大，且未核验内容。
- 第三方参考模型目录（OpenParallelGripper、哈工程 R1R2、ST3215 快照、C-MLG7 等）**不应**混入本项目 CAD 发布。

## 5. 如果以后要公开 CAD

建议先做以下决策（本轮不执行）：

1. **授权**：逐项确认团队 CAD、外购件模型、第三方参考模型的可再分发范围。
2. **版本**：只保留最终 `总装` 及必要的底盘/升降/夹爪装配；删除 `车 (1)`、`~$`、`.dwl/.dwl2`、旧 `电梯next`、重复 STEP。
3. **格式**：GitHub 不能预览 SolidWorks；优先提供最终装配的 STEP/STL 预览，原生文件另附。
4. **LFS**：若确实要提交原生 CAD/大 STEP，先提出 Git LFS 方案并确认，不能直接改仓库配置。
5. **体积**：不要上传 190 MB 全目录；先做文件级筛选和体积预算。
6. **隐私/第三方**：检查标题栏、文件名、供应商标识、第三方模型来源；含个人信息或保密标识的图纸默认不公开。
7. **验证**：用 SolidWorks/STEP 查看器检查装配、干涉、质量和 BOM 后再发布。

**BLOCKED（未授权，不公开 CAD）**。这不妨碍机械文档的公开；CAD/图纸待授权与清理后再单独处理。
