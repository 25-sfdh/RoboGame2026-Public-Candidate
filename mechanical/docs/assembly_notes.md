# 装配、调试与维护记录

本页整理机械装配/调试中**有文件依据的流程与必须核对的工程项**。没有现场记录的部分标为【待核实】；不要把它当成已经完成的装配验收报告。

## 1. 装配接口

### 1.1 底盘 → 门架

- 门架立柱固定在底盘车架上；需要确认立柱底座、角码、连接板和螺钉规格。
- 门架根部承受升降+夹爪的前翻力矩，是优先检查的受力节点。
- 需要确认底盘上平面平面度、立柱垂直度、左右立柱平行度和对角线。

### 1.2 一级电梯 → 二级电梯 → 夹爪

- 一级电梯在门架内由链条/链轮驱动；二级电梯安装在一级滑台上。
- 二级电梯与夹爪连接板之间通过滑台/连接件相连；计划书提到绳子和重力补偿装置，最终结构待确认。
- 需要检查：导轨平行度、滑块预紧、链条张紧、链轮共面、限位块位置、夹爪层间距。

### 1.3 三层夹爪

- 每层夹爪通过连接板/铝件/打印件固定在二级滑台上。
- 需要确认：三层夹爪的同轴/层间距、左右夹指对称、齿轮/齿条啮合、推杆行程、橡胶垫位置、前端导向口。
- 三层同时外伸时，门架承受最大前翻力矩；应避免末端过重。

## 2. 建议的装配顺序（来自计划书，未记录实际执行）

1. 组装底盘框架，用直角尺/对角线检查四角方正。
2. 安装轮组/电机模块，确认四轮等高、轮组无晃动。
3. 安装门架立柱和一级/二级导轨，先手动推动滑台确认无卡滞。
4. 安装链轮/链条/张紧支架，检查链轮共面、链条松紧和运行噪声。
5. 安装二级电梯/绳/重力补偿，确认升降全程无干涉。
6. 安装三层夹爪，逐层手动开合，确认导向口、行程和层间距。
7. 安装舵机/推杆/线束，低速空载运行，再逐步带载。
8. 检查急停、断电、限位和防坠；完成整机复检。

**注意：** 这是计划书/工程经验的顺序，不是本项目的实际装配日志；实际顺序、扭矩和调试结果没有记录。

## 3. 关键装配检查

| 检查项 | 为什么重要 | 当前证据 |
| --- | --- | --- |
| 框架方正/对角线 | 门架和导轨的安装基准 | 计划书要求；无实测记录 |
| 导轨平行/共面 | 双导轨卡滞、滑块偏载 | MGN12C 导轨存在；无平行度测量 |
| 链轮共面/链条张紧 | 跳齿、磨损、噪声、升降抖动 | 05B 链轮/链条/压紧支架存在；无张紧力记录 |
| 二级绳/重力补偿 | 二级升降负载与同步 | 计划书描述；CAD 文件名未直接确认 |
| 限位块/限位开关 | 防止过行程/坠降 | 二级下方备用限位块存在；一级限位/开关证据不足 |
| 夹爪齿轮/齿条啮合 | 夹持同步、回差、卡滞 | 齿轮/齿链零件存在；未打开装配体验证 |
| 夹指对称/导向 | 方块进入与夹持姿态 | 计划书/照片；无夹持力/对中数据 |
| 线束固定 | 运动干涉、断线、磨损 | 照片可见线束；无拖链/固定点记录 |
| 螺钉防松 | 振动下松动 | 标准型材/角码；无扭矩/防松记录 |

## 4. 线束与运动副

- 升降和夹爪至少有两级运动：门架升降、夹爪开合；若存在横移，还会增加第三级。
- 线束应固定在非运动区域，运动段留弯曲余量；不能兼作限位或承力件。
- 需避免动力线与编码器/信号线过紧捆扎，避免插头承受拉力。
- 照片中线束沿门架布置，但没有拖链型号、弯曲半径、固定点、磨损或断线记录。

## 5. 调试与验证建议

以下测试是工程建议，**不是已经完成的结果**：

- 空载升降全程：听异响、看链条跳动、测滑台直线度；
- 带载升降：三层夹爪 + 最大方块数，记录电流/温升/抖动；
- 夹爪单层开合：确认 0–127 mm 范围、夹指同步、橡胶垫接触；
- 夹爪三层同时动作：确认层间干涉、电源瞬时电流、线束拉扯；
- 14° 坡道：上下坡、横移、急停，观察掉块/点头/门架摆动；
- 放置：卸力—松夹—后撤，检查是否蹭倒已搭方块；
- 连续循环：检查链条张紧、螺钉松动、打印件磨损、限位块位置。

## 6. 安全注意事项

- 升降/夹爪有夹点，调试时应断电或使用低速/空载模式。
- 三层夹爪同时外伸时整机前翻风险增大，应在门架前方留出安全距离。
- 泡沫块掉落不会造成大伤害，但门架/电池/工具坠落有风险；急停和断电必须可触达。
- 不建议在没有限位/防坠措施的情况下直接带载全速升降。
- 不能把“代码能跑”当成“机械安全验收”。

## 7. 维护

- 链条：定期检查张紧、润滑、链轮磨损和链节卡滞。
- 导轨/滑块：检查润滑、异响、间隙和安装螺钉。
- 夹爪：检查齿轮/齿条啮合、打印件裂纹、橡胶垫磨损、推杆行程。
- 紧固件：门架根部、轮组、导轨、链轮支架和夹爪连接板优先复检。
- 备件：当前没有 BOM/备件清单；建议至少准备链条、链轮、打印连接件、橡胶垫和常用螺钉。
