# 三层夹爪机构

本页整理末端夹爪的机械方案。夹爪舵机 ID 0–2、角度预设和任务动作编排属于代码部分，见根目录 README、`docs/architecture.md` 与 `docs/software_structure.md`。

## 1. 设计输入

内部设计检查清单/风险报告给出的夹爪约束：

- 对象为约 100×100×100 mm 泡沫方块，存在尺寸误差；
- 材料槽深约 50 mm，夹爪不能依赖厚底托强行插槽；
- 一次最多携带 3 块方块，最多 1 块紫块；
- 全自动运行，运输中掉块不能人工放回；
- 场地约 14° 坡道，需考虑上下坡、急停和横移冲击；
- 放置后建筑需稳定约 3 s；
- 末端应轻、前伸应短，避免放大门架前翻力矩。

## 2. 结构方案

2026-05-05《执行机构计划书》给出的方案是：

- 三层独立夹爪 + 竖直门架升降；
- 每层一组夹爪，三层可独立控制；
- 夹爪由电机驱动，通过滑轨实现直线运动；
- 单电机驱动的对称齿条夹爪；
- 抓取范围 0–127 mm，对称夹持；
- 夹持面增加橡胶垫，结构预留弹性空间以适应泡沫块误差；
- 前端增加开口大于方块、向中心内收的导向结构。

这解释了三层布局的工程逻辑：一次对准多层目标，减少反复升降；同时把夹持动作分配到每层，避免整组夹爪只抓一块。

## 4. 两个夹爪版本

- `夹爪装配.SLDASM`
- `无伸缩夹爪装配.SLDASM` / `无伸缩夹爪带滑块.SLDASM`

可以确认的是**至少存在两个夹爪版本**，其中一个是“无伸缩”结构。不能确认：

- 哪个版本是最终比赛版本；
- 两个版本的先后顺序；
- 为什么改为无伸缩；
- 无伸缩版本是否解决了前伸/干涉/重量问题；
- 两个版本的夹持范围、夹持力和零件差异。

最终采用哪个版本、两个版本的先后顺序、无伸缩改动是否落地，仍属于【待核实】；但“本人完成三组夹爪四项设计”已由本人确认。

## 5. 驱动方式：设计文档中的分歧

内部资料对驱动方式有不同取舍：

- 2026-04-11《夹爪风险报告》《夹爪与升降机构设计总结》倾向**气动主工作位 + 轻量转运位**，并提醒空压机质量（约 12 kg）不现实；
- 2026-05-05《执行机构计划书》改为**每层电机驱动、单电机对称齿条**；
- 最终 CAD 中出现 ST3215 舵机、齿轮/齿链和迷你电动推杆，未见气路元件文件名。

**可支持的结论**：设计早期认真比较过气动与电动，后期计划/CAD 明显转向电动舵机/齿条方案。  
**不能支持的结论**：为什么最终放弃气动、是否完全放弃、是否仍保留气动辅助、最终夹持力是否足够。

## 7. 抓取与放置的工程分析

设计文档提出的关键点（属于工程分析，不是实测结论）：

- 泡沫块轻、表面易滑，夹持力不是越大越好；应通过背板、侧夹、薄唇边/托边、防滑垫和前端导向形成几何限位；
- 完整厚底托不容易插入 50 mm 深槽，入口应做倒角/V 形/喇叭口；
- 夹指过高可能压块，过低可能碰槽边；
- 运输上坡、急停和横移停止时，方块可能下滑或前滑；
- 放块应遵循“卸力 → 松夹 → 后撤”，避免夹爪蹭倒已搭建筑；
- 三层同时外伸会增加门架前翻力矩，应尽量缩短前伸、降低末端质量。

这些是合理的设计原则，但当前没有夹持力、摩擦系数、夹爪变形、方块损伤或 3 s 稳定性测试数据。
