# 竖直升降机构

本页整理门架/电梯机构。升降的电机控制、舵机 ID 3 和任务时序属于代码部分，见[仓库主 README](../../README.md) 与 [系统架构](../../docs/architecture.md)。

## 1. 设计输入

- 三层夹爪需要覆盖取料、运输和搭建的不同高度；
- 夹爪和方块位于门架前端，升降时产生前翻力矩；
- 场地有约 14° 坡道，启停和过坡会放大动态载荷；
- 机器人展开高度规则上限 1000 mm，初始高度上限 600 mm；
- 设计文档建议双导轨、拉开导轨间距、控制末端质量和前伸。

## 3. 结构原理

从文件名、计划书和照片可以支持的描述：

1. **一级升降**：门架立柱 + 直线导轨 + 一级滑台；链条/链轮驱动一级滑台上下。
2. **二级升降**：一级滑台上再叠加二级立柱/滑台，由链条或绳/联动机构带动，使夹爪获得更大高度。
3. **导向**：MGN12C 系列直线导轨承受侧向和弯矩载荷；双导轨布置用于提高抗扭/抗偏载能力。
4. **传动**：05B 单排链轮 + 链条；链轮文件名含 `05B-14`、`05B-18` 两种规格（数字是否代表齿数需以图纸确认），可能对应不同速比或不同版本，具体搭配需按装配体确认。
5. **张紧/限位**：CAD 中有链条压紧支架和二级电梯下方备用限位块；是否装限位开关、一级是否有对应限位块，资料不完整。
6. **重力补偿**：计划书提到二级电梯与夹爪之间的绳子和重力补偿装置；本轮没有在 CAD 文件名或照片中独立确认其最终结构。

以上是**结构层面的合理重建**，不是对装配体内部配合的确认。

## 4. 行程、负载与稳定性

### 4.1 行程

- 计划书：550→910 mm（不含底盘）≈ 360 mm 行程；
- 历史线索：约 400 mm；
- 导轨型号：MGN12C-1-R-500，型号中的 500 仅为候选长度标识，实际导轨长度尚待产品样本、采购记录或实测确认；
- 结论：最终行程必须用装配体尺寸或实车测量确认，当前不能写死。

### 4.2 负载

- 设计目标：门架 < 4 kg（历史线索/设计目标）；
- 末端：三层夹爪 + 最多 3 个泡沫方块；
- 实际质量、重心、导轨额定载荷、链条破断力、链轮/轴承载荷均未计算或测量。
- 不能把“设计目标 < 4 kg”写成“实测门架质量”。

### 4.3 稳定性

设计文档的风险判断是合理的：

- 三层夹爪前伸 + 方块重心使门架承受前翻力矩；
- 双导轨、拉开导轨间距、降低末端质量、缩短前伸可以降低风险；
- 14° 坡道、启停冲击和放置碰撞会放大动态力矩。

但没有 FEA、倾覆试验、导轨变形测量、链条振动/寿命试验或比赛故障日志，不能声称“稳定性已通过验证”。

### 4.4 个人参与与驱动更换

- 本人参与升降机构的早期设计/SolidWorks 建模；本人判断最终结构与早期方案差异不大（需按最终 CAD 对照）。
- 2026-08 第二次评审前，升降实测阻力大于预期；团队将原 M3508 方案改为 **45 kg 级舵机** 后才实现升降。这次驱动更换由其他成员完成，**不属于本人贡献**。
- 没有阻力曲线、电流、装配同轴度或导轨预紧记录，不能判断问题主要来自摩擦、导轨装配、传动效率还是驱动器选型；也不能简单断言“舵机扭矩一定比 M3508 大”。
- 45 kg 级舵机的具体型号、安装座、输出轴/传动接口和限位方案仍需核实。

## 5. 已知问题/待验证

- 一级/二级电梯的最终装配关系、绳/链联动方式；
- 链条张紧力、链轮对齐、链条润滑和寿命；
- 一级/二级限位块是否完整，是否有限位开关/软件限位；
- 二级绳/重力补偿是否实际安装，效果如何；
- 45 kg 级舵机的型号、安装座、传动接口和限位；
- 550/910 与 400 mm 行程的冲突；
- 门架质量、整机重心、导轨载荷和坡道倾覆余量；
- 升降过程中夹爪/线束/方块与门架的干涉；
- 比赛现场是否出现链条跳齿、卡滞、异响、限位失效等问题。

## 6. 与夹爪/底盘的接口

- 门架立柱固定在底盘车架上；根部连接板和角码是优先检查的受力节点。
- 二级滑台与三层夹爪连接板相连；夹爪前伸会把弯矩传回滑台和导轨。
- 升降线束沿门架运动，照片可见线束但没有拖链/固定点记录；线束不能兼作限位或承力件。
- 代码中的 ID 3 控制升降舵机；机械侧需要确认舵机输出与一级/二级传动的对应关系，不能只看代码推断机械结构。
