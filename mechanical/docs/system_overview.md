本页只讨论机械结构与总体布置。控制、视觉和任务流程的说明见[仓库主 README](../../README.md)、[系统架构](../../docs/architecture.md) 与 [软件结构](../../docs/software_structure.md)。

## 2. 总体布局

![机器人整体](../../media/robot-overview.jpg)

从照片和 CAD 目录可以确认的总体布局：

- 四轮麦克纳姆轮底盘，四个轮组位于车架四角；每个轮组对应一个电机模块。
- 车架由 2020 工业铝型材、角铝/角码和连接板组成，属于螺栓连接的框架结构。
- 车架上方是竖直门架；门架内有一级/二级升降滑台，前端挂三层夹爪单元。
- 电池、电控、舵机驱动和接线集中在底盘/门架下部；照片中可见急停按钮和大量线束。
- 夹爪面向场地一侧，工作时需要前伸进入材料槽；运输时希望缩短前伸、降低前翻力矩。

从任务流程看，底盘负责到达取料区/搭建区，门架负责高度，三层夹爪负责一次携带多块方块。视觉对位和循迹是并行的感知/运动问题，不属于机械结构本身。

本人确认：`media/` 中的实物照片对应比赛使用的最新机械版本实车。照片能证明可见结构，不能证明作者、最终 CAD 版本或性能。

## 4. 载荷路径与刚度

从可见结构推断的载荷路径：

1. 方块/夹爪重力与惯性力 → 三层夹爪连接板 → 二级电梯滑台；
2. 二级滑台 → 一级电梯/门架立柱 → 底盘车架；
3. 车架 → 轮组/电机模块 → 地面。

设计文档明确建议：

- 采用双导轨、拉开导轨间距，降低单侧受力引起的卡滞和摆动；
- 门架两侧增加加强板，使用铝型材框架；
- 降低末端质量、缩短导轨中心到方块重心的前伸；
- 把下层作为主工作位、把重件尽量放在底盘内侧。

这些是**设计分析/方案建议**。现有资料没有 FEA、应变测量、倾覆试验、模态测试或重复定位数据，因此不能声称“刚度已满足”“不会振动”或“过坡稳定”。

## 5. 装配与维护

- 框架使用标准 2020 型材和 20B 角铝，理论上便于采购、切割和更换；但原归档存在两套完整重复目录和大量 `~$`、`.dwl/.dwl2` 锁文件，说明版本/副本管理需要清理。
- 门架、一级/二级电梯、夹爪和底盘均为独立装配体；模块化有利于单模块调试，但接口尺寸、螺钉规格、扭矩和备件清单没有形成 BOM。
- 三层夹爪、链条、链轮和导轨都在运动链上；维护需要检查链条张紧、链轮对齐、导轨润滑、限位块和线束固定。
- 照片中线束沿门架布置，但没有拖链型号、弯曲半径、固定点或磨损记录。

## 6. 机械与感知/控制的接口

- 升降和夹爪由舵机/电机驱动，代码中的 ID 3 与 ID 0–2 只是控制通道；机械侧需要确认每个 ID 对应的实际关节、零点和限位。
- 视觉对位误差会转化为夹爪入口的横向/纵向偏差；机械设计通过前端导向口、倒角和薄唇边降低对位要求，但具体尺寸未记录。
- 麦克纳姆轮底盘的运动学/循迹算法由代码实现，不能把算法能力写成机械设计成果。
