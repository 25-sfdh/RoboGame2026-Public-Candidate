## 图片与机械结论的边界

照片能证明“可见结构”，不能证明内部配合、材料、尺寸或性能：

- 能看到四轮麦轮、门架、链条、三层夹爪和电控；
- 不能从照片量出轴距、轮距、升降行程、夹持力或质量；
- 不能从照片判断最终是 `夹爪装配` 还是 `无伸缩夹爪装配`；
- 不能从照片证明比赛成功率或机械可靠性。
