## 如果要补 BOM

建议至少包含：

- 零件号/名称/版本；
- 规格型号（电机减速比、舵机型号、导轨长度、链轮齿数等）；
- 数量（每台份）；
- 材料/表面处理；
- 加工方式（采购/3D 打印/激光切割/CNC/车铣）；
- 供应商/采购链接（若公开）；
- 单件质量；
- 装配位置/所属子装配；
- 备件数量；
- 是否第三方模型/是否有再分发许可。

## 公开与授权

- BOM 可能暴露供应商、价格、采购渠道或第三方模型信息；公开前需确认。
- 第三方开源夹爪的 BOM 不能直接并入本项目，除非确认其许可证和署名要求。
- 本轮不创建虚构 BOM，也不根据照片猜数量/规格。
