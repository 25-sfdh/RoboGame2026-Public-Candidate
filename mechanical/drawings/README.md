## 公开前的检查

如果以后要公开这些图纸，先确认：

1. 图纸由团队绘制，或已获得原绘图者/供应商的再分发许可；
2. 标题栏不含个人姓名、学号、电话、供应商报价、内部项目号等不适合公开的信息；
3. 图纸版本与最终 CAD/实物一致；
4. DWG 是否需要同时提供 PDF/DXF 便于 GitHub 预览；
5. 图纸不包含未授权的第三方模型/标准件细节。

**当前状态：** 不公开。图纸不是代码 MIT 的自动覆盖范围；未确认授权前，只在本说明中记录存在性，不复制文件。
