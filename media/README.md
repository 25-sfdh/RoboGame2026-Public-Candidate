## 隐私与来源记录

公开副本按 JPEG 结构清理：移除 EXIF/XMP、IPTC、COM、厂商 APP3/APP4 及 EOI 之后的所有数据。team-award.jpg 的旧副本包含 EOI 后的 Live Photo MP4，本次全部移除；三张比赛截图各有 24 字节尾注，也已移除。音视频未播放或用于项目结论。

其余四张图片保留 APP0 JFIF；team-award.jpg 无 APP0，仅保留 APP2 ICC_PROFILE（含标记共 650 字节，长度字段为 648）以保持色彩配置。ICC 含通用厂商版权文字，已明确记录，不声称清除了所有非像素段。五张图片均可正常解码，EOI 后为零字节；相对本次修复前的候选副本，解码像素、图像编码数据与 ICC 色彩配置一致。画面未裁剪、重绘、缩放或重编码，可见水印保持。

原图哈希与公开副本哈希分开记录在 [SOURCE_MANIFEST.json](../SOURCE_MANIFEST.json)，公共来源采用 attachment-1 至 attachment-5，不写本机账号、绝对来源路径或内部工具文件名。最初整理时对原图含 GPS 的记录保留为历史检查说明；本轮验证对象为已有候选副本。
