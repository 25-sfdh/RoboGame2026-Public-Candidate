# Lessons Learned

这个项目把机械结构、传感器、视觉、串口/GPIO 和任务时序放在同一台机器人里。对本科低年级参与者而言，成长主要体现在从阅读和调试单模块，转向理解一个模块的输入、输出和失败如何影响下一阶段。

代码里有能直接讨论的工程例子：用多帧确认减少瞬时判断，用实际角度读回代替只相信舵机指令，定位失败时阻止抓取。也有待改进的例子：线程结束不保证成功，重试次数达到上限不等于动作完成，定时位移不等于测得的位置闭环。理解这些边界，比泛称“开发导航算法”更能说明学习过程。

## 从工程记录走向研究

| 方向 | 先补的条件 | 一项可审阅的产出 |
| --- | --- | --- |
| ROS 2 | 明确数据接口，学习节点、消息、参数和记录/回放 | 在独立版本中接入一个传感器或底盘接口，并保存数据回放演示 |
| 状态估计与 SLAM | 核实编码器/里程计可用性，建立坐标关系，再考虑合适的建图传感器 | 先报告里程计误差与 TF，再做地图/定位实验；现有硬件不自动具备这些能力 |
| Robot Learning | 定义观察、动作、任务成败与可信规则基线，采集经授权的轨迹数据 | 对单一对位或操作任务做示范学习对比，并区分训练与测试条件 |
| Reinforcement Learning | 建立可复现仿真、动作范围、奖励、终止条件和独立评价环境 | 多个随机种子下与规则基线比较；真机验证作为后续独立步骤 |

ROS 2 官方学习路径覆盖通信、工具与数据回放，适合作为模块化学习起点。[ROS 2 First Steps](https://github.com/ros2/ros2_documentation/blob/rolling/source/First-Steps.rst)

Nav2 的官方机器人设置指南把坐标变换、模型、里程计、传感器及建图定位列为基础环节；当前仓库不能直接跳过这些环节获得 SLAM。[Nav2 Robot Setup](https://docs.nav2.org/rolling/configuration_and_development/first_time_robot_setup_guide/)

示范数据和离线学习可以参考 robomimic 的任务与数据流程；这里将其作为未来实验参考，不声称本项目已采用。[robomimic](https://robomimic.github.io/)

强化学习应做定量实验、独立测试环境与多次运行评价；训练曲线本身不能代替任务验证。[Stable-Baselines3 实验建议](https://stable-baselines3.readthedocs.io/en/master/guide/rl_tips.html)

这些方向不能替代控制理论、数据结构与算法、C++、机器人学和概率估计的系统学习。它们是未来分阶段升级，不是本仓库已有功能。
